# Taskly — Minhas tarefas

Aplicação responsiva em português com React, TypeScript, Vite e Tailwind CSS. Permite criar, editar, concluir e excluir tarefas, desfazer exclusões, buscar e filtrar por estado. Os dados ficam no localStorage do navegador, sem login ou sincronização.

```sh
npm install
npm run dev
```

`npm run build` valida os tipos e gera a versão de produção em `dist`. `npm run lint` executa a verificação estática de tipos do TypeScript.
