# Projeto: teste de interface

## Regras gerais
- Responda sempre em português do Brasil.
- Crie e edite os arquivos diretamente com as ferramentas; não cole o código inteiro no chat.
- Faça só o que foi pedido, sem funcionalidades extras.
- Ao terminar, diga em uma ou duas frases o que foi feito.

## Código
- Projeto em um único `index.html`, com HTML, CSS e JavaScript juntos.
- Não use frameworks, bibliotecas externas nem CDN.
- JavaScript puro (vanilla), sem build e sem npm.
- Use `const` e `let`, nunca `var`.
- Nomes de variáveis e funções em inglês; textos da interface em português.

## Visual
- Estilo moderno: cantos arredondados, sombra suave, espaçamento generoso.
- Layout responsivo, que funcione em tela de celular.
- Defina cores como variáveis CSS (`:root`), para facilitar mudar de tema.

## Edição
- Ao alterar um arquivo existente, mude apenas o trecho necessário.
- Não reescreva o arquivo inteiro sem necessidade.
